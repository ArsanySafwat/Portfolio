Project

Superstore Data Warehouse & Business Analytics

SQL Server · Star schema · Medallion architecture

I turned a flat Excel sales file (Central region of the Superstore dataset) into a structured data warehouse, then wrote SQL to answer business questions about profitability, customer behavior and sales trends.

How it's built

BronzeRaw data loaded as-is
SilverCleaned and standardized
GoldStar schema: 6 tables

The gold layer has one fact table (fact_sales) and five dimensions: customer, product, location, ship mode and date.

What's inside

Views and stored procedures for reuse, 15+ analytics queries using joins, CTEs, subqueries and CASE logic, and an optimization pass to make queries faster.

A problem I caught

While checking my SQL against the real data, I found 16 product IDs that appeared under inconsistent product names. I fixed it with a clear rule: each product keeps the name from its most recent order. Without that fix, product-level totals would have been split or wrong.
